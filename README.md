# MathRise 💜

Welcome to **MathRise**! 📚✨

MathRise is an interactive **AI-powered mathematics learning platform** designed to help students understand mathematics, practice their skills, identify their weaknesses, and improve their academic performance.

## 🌟 Features

- 📚 Explore mathematics courses from **First Secondary to Third Secondary**
- 📖 Access lessons and learning materials
- 📝 Test yourself through quizzes and assessments
- 📄 Assess previous mathematics exams
- 🤖 Get help from the **AI Math Tutor**
- 📊 Track your learning progress
- 🧠 Identify weaknesses and receive a personalized development plan
- 🗒️ Save and keep your own notes

## 🤖 AI & RAG Features

### 🧮 AI Math Tutor

The AI Math Tutor helps students understand mathematical concepts through clear, step-by-step explanations and answers to their mathematics questions.

### 🔎 Retrieval-Augmented Generation (RAG)

MathRise uses **RAG** to retrieve relevant information from the mathematics learning materials and use it as context for AI-generated responses.

### 📊 Smart Assessment

The platform analyzes students' answers and mistakes to provide feedback and help identify areas that need improvement.

## 🛠️ Technologies Used

- Python
- Streamlit
- Generative AI
- RAG
- Vector Search / Embeddings
- PDF Processing
- GitHub
